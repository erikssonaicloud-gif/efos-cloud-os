# Cycle 1 review package
Start with the litigation readiness review, then the conservative replacement report draft. DOCX and Markdown versions contain the same substantive text.

The source website was captured on October 19, 2026. It has not been modified. The original HTML snapshot is retained as evidence of what was reviewed; it is not an endorsed or newly authored presentation. Saved primary-document text captures are under sources/.

Reproduce: install requirements.txt, then run `python reproduce_audit.py`. Input data are transcribed from the displayed table, not validated raw measurements. audit_results.txt contains the run output. The CSV register links corrections to slide numbers, including narration.

HASH_MANIFEST.csv lists SHA-256 digests for captured and generated files except the manifest itself and the containing ZIP. Hashes preserve byte integrity of these copies, not source authenticity or substantive truth.

No original satellite files, permits, private medical records or retained-expert certifications are included. Legal issues require forum-specific counsel review.
